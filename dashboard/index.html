Kotlin/Native + JVM

HTTP serving,
built in Kotlin.

Build HTTP services with a compact Kotlin routing API. Run ktServe as a standalone server or use it as the engine in Ktor and Spring Boot WebFlux.

Get started ↓ Explore use cases ↓
Application.ktKotlin
import codes.draeger.ktserve.*

fun main() {
    serve(port = 8080) {
        get("/health") { text("ok") }
    }
}

Kotlin quickstart

Add ktServe to Gradle

repositories { mavenCentral() }

dependencies {
    implementation("codes.draeger:ktserve:0.4.0")
}

Run your first route

Use JDK 21 for a JVM app. Run Application.kt above and call its health endpoint.

curl -fsS http://127.0.0.1:8080/health

HTTP/1.1

The standalone server supports persistent connections and streaming bodies on Native and the JVM.

Direct HTTPS

Serve HTTPS directly from ktServe with your own PEM certificate and key. The Linux CLI preview runs HTTP/1.1 over TLS 1.2 and 1.3 using OpenSSL 3.

Why ktServe stays small

The standalone library adds just two direct dependencies beyond the Kotlin standard library, both official kotlinx libraries for coroutines and JSON serialization. That’s it!
