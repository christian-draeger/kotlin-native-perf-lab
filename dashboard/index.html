Kotlin quickstart

Add ktServe to Gradle

repositories { mavenCentral() }

dependencies {
    implementation("codes.draeger:ktserve:0.4.0")
}

Run your first route

Use JDK 21 for a JVM app. Run Application.kt above and call its health endpoint.

curl -fsS http://127.0.0.1:8080/health

Terminal quickstart

Download the CLI

Use Bash or zsh for the inline examples. Compiling Kotlin requires a JDK and, on macOS, full Xcode.

Downloads and build requirements ↗

Serve a directory

./ktserve serve ./public

Serve inline JSON

./ktserve serve - <<<'{"status":"ok"}'

Run a Kotlin route

./ktserve run - <<<'get("/health") { text("ok") }'

From a second terminal, call curl -fsS http://127.0.0.1:8080/health.

Configure an app inline

./ktserve run --app - <<'KOTLIN'
serve(port = 8081) {
    get("/health") { text("ok") }
    get("/ready") { text("ready") }
}
KOTLIN

Run a Kotlin file

Save the Kotlin example above as App.kt and run it.

./ktserve run App.kt

A small core. Add what you need.

Validate incoming data, generate OpenAPI, or add tracing when your service needs it. Each extension is a separate dependency you install explicitly. Leave unused modules out of your server build.
